# 智翼守护 GuardianWing

> **Smart Walker × AI Care Platform** — 让行走，不再是一个人的事。

![GuardianWing](logo.png)

## 项目简介

GuardianWing（智翼守护）是一款面向独居长者的 **智能助行器 + AI 主动关怀平台**。我们通过在传统助行器上加装多传感器模组，结合 AI 电话关怀引擎，打造从"跌倒检测"到"主动健康干预"的完整守护闭环。

### 核心痛点

- 🚶 **跌倒恐惧**：全国 4000 万独居长者，跌倒后平均需 77 分钟才能获得救助
- 😔 **孤独感**：65 岁以上长者日均社交不足 30 分钟，孤独感是健康的第一隐形杀手
- 📊 **健康黑盒**：子女不在身边，无法实时了解父母日常行动状态与异常

### 我们的方案

| 模块 | 功能 |
|------|------|
| 🦯 **智能助行器** | 多传感器融合（毫米波雷达 + 姿态传感器 + 压力感应），实时检测步态异常与跌倒 |
| 🤖 **AI 电话关怀** | 检测到异常后自动拨打 AI 电话，多轮对话确认状态，必要时通知紧急联系人 |
| 💗 **健康飞轮** | 每一次对话数据反哺健康画像，越用越懂长辈的身体规律 |
| 👨‍👩‍👧 **家人端** | 微信小程序实时查看行动轨迹、异常预警与每周健康报告 |

## 功能亮点

### 🌐 双语支持
- 全平台 **中文 / 英文** 无缝切换，面向国际化展示

### 🎮 互动演示
- 5 步完整守护闭环演示：
  1. 选择长者画像（张奶奶 / 李爷爷 / 王奶奶）
  2. 助行器实时传感 + 步态异常检测

  - 设置

## 快速开始

### 方式一：直接打开（推荐用于提交/分享）

直接双击以下文件即可运行，无需任何依赖：

- **单文件版首页**：`index_standalone.html`
- **单文件版体验中心**：`dashboard_standalone.html`

> 单文件版已将所有 CSS/JS/图片（Logo）内联为 Base64，发给别人直接打开即可完整展示。

### 方式二：本地服务器

```bash
# 克隆项目
git clone https://github.com/wondacly/GuardianWing.git

# 进入目录
cd GuardianWing

# 启动本地服务器（任选其一）
python -m http.server 8000
# 或
npx http-server -p 8000

# 浏览器访问
# http://localhost:8000/
```

## 设计理念

> **"So aging never means walking alone."**

我们相信，科技的终极意义是让每一位长者都能有尊严地、安全地独立生活。GuardianWing 不是一台冷冰冰的助行器，而是一位 24 小时在线的"隐形陪伴者"——

- **不打扰**：仅在检测到真正的风险时才介入
- **有温度**：AI 电话使用自然的口语化表达，而非机械提示
- **可进化**：每一次交互都让系统更懂用户
